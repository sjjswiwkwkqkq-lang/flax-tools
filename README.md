# flax-tools

Постоянное хранилище движка **Flax Engine 1.12.6912** и инструментов сборки под Android.

Лежит здесь, чтобы песочница могла восстановить движок в любой момент
даже после полного сброса.

## Что внутри релиза

| Файл | Размер | Что это |
|---|---|---|
| `FlaxEditorLinux.zip` | 217 МБ | Редактор Flax под Linux |
| `Android.zip` | 158 МБ | Бинарники ARM64 + Gradle-проект |
